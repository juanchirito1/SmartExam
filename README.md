# SmartExam

Sistema web para la gestión de simulacros académicos mediante lectura automática de fichas ópticas.

## Objetivo

Desarrollar una plataforma que permita administrar simulacros académicos, registrar postulantes, generar carnets de participación, procesar fichas ópticas mediante cámara y emitir resultados agrupados por carrera.

## Tecnologías

Frontend:
- Next.js
- TypeScript

Backend:
- NestJS
- TypeScript

Base de datos:
- PostgreSQL
- Prisma ORM

Procesamiento de imágenes:
- Python
- OpenCV

## Módulos principales

- Gestión de usuarios y permisos.
- Registro de alumnos.
- Administración de simulacros.
- Generación de carnets.
- Lectura automática de fichas ópticas.
- Cálculo de puntajes.
- Reportes por carrera.
